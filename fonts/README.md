# Polices

Déposez ici un fichier `.ttf` / `.otf` (idéalement une police monospace ou pixel
sous licence libre, ex. OFL) : le premier trouvé dans ce dossier sera utilisé
automatiquement pour générer l'atlas de glyphes.

Si le dossier ne contient aucune police, le jeu utilise une police monospace du
système (Consolas, DejaVu Sans Mono, Liberation Mono…), puis en dernier recours
la police par défaut de Godot.

Suggestions (licence OFL) : JetBrains Mono, IBM Plex Mono, Press Start 2P,
Px437 / "Ultimate Oldschool PC Font Pack" (CC BY-SA). Pensez à joindre le
fichier de licence de la police à côté du `.ttf`.
